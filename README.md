# PathSnap: Distributed Map-Matching & Route Reconstruction

UE24CS352A Machine Learning hackathon, PES University (RR Campus).

PathSnap snaps noisy GPS traces onto a road network and reconstructs the route a vehicle actually
drove. Each GPS point gets a few nearby candidate road segments. A trained classifier scores them,
and an HMM with Viterbi decoding combines those scores with road-network connectivity to return
one continuous, physically possible route.

```
raw trip  ->  local metric projection  ->  candidate arcs (KD-tree, R=50 m, K=10)
          ->  16 features per candidate ->  classifier P(true arc)  (LightGBM, Optuna-tuned)
          ->  HMM / Viterbi  (emission = classifier prob, transition = route vs straight-line distance)
          ->  gap-filled continuous route  ->  FastAPI (Laptop 1)  ->  evaluator UI (Laptop 2)
```

## Setup

Python 3.11 or newer.

```bash
python -m venv .venv
source .venv/Scripts/activate        # Windows Git Bash   (macOS/Linux: source .venv/bin/activate)
pip install -r requirements.txt
```

The raw data is not committed. Put the organisers' `Student folder` (with `train/` and `student_test/`)
in the project root or its parent folder, or point to it with `PATHSNAP_DATA=/path/to/Student folder`.

## Reproduce every result (run from the project root, in order)

```bash
python -m features.build_dataset     # labels + candidates + features  -> artifacts/*.parquet, results/p1
python -m eda.run_eda                # EDA tables, figures, Folium map  -> results/eda
python -m models.train_models        # 8 models, 5-fold GroupKFold CV   -> results/p2
python -m tuning.optuna_search 30    # Bayesian optimisation + final model -> artifacts/final_model.joblib
python -m hmm.evaluate_hmm           # decoder tuning + HMM comparison  -> results/p3, artifacts/hmm_params.json
```

## Deployment (two laptops)

**Laptop 1, API.** It needs the project, `artifacts/` and the evaluation trips folder:
```bash
set PATHSNAP_EVAL_DIR=D:\path\to\evaluator_trips      # Windows cmd (default: student_test)
uvicorn api.main:app --host 0.0.0.0 --port 8000
```
Every request is logged in this console (trip, accuracy, timings). Find the laptop's IP with `ipconfig`,
and allow Python through the Windows firewall on private networks.

**Laptop 2, UI.** It needs only the `ui/` folder:
```bash
pip install -r ui/requirements.txt
streamlit run ui/app.py
```
Enter `http://<laptop-1-ip>:8000` in the sidebar, pick a trip and press **Reconstruct route**.
Reference routes stay on Laptop 1. The UI only receives the GPS trace, the predicted route and the metrics.
